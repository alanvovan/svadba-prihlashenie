# Агенты для личного свадебного лендинга

Минимальная подборка из [agency-agents](https://github.com/msitarzewski/agency-agents): только вёрстка, структура и визуал. Без маркетинга, SEO и «продукта».

## Файлы

| Файл | Роль |
|------|------|
| `engineering/engineering-frontend-developer.md` | HTML/CSS, адаптив, семантика, аккуратная статика. |
| `design/design-ui-designer.md` | Типографика, отступы, кнопки, карточки, общий вид страницы. |
| `design/design-ux-architect.md` | Какие блоки в каком порядке, якоря, путь гостя до RSVP. |
| `design/design-visual-storyteller.md` | Настроение и «голос» приглашения (тёплый тон без рекламного шума). |

## Как использовать

Скопируйте текст нужного `.md` в промпт чата или в Custom Agent в Cursor. Оригиналы на GitHub обновляются независимо — при необходимости скачайте заново с `raw.githubusercontent.com/msitarzewski/agency-agents/main/...`.
